## 二之一、第一轮的"待修"清单原文（均已解决，保留追溯）

**中高**
1. **CJK 粘连拉丁词整词失效**：`npm包`/`git仓库`/`v2版本` 这类查询在 FTS5 下命中 0，纯 CJK 子串却命中
   （`cjk.ts:68-84` 的 `cjkClause` 对整词取 bigram，跨 ASCII/CJK 边界的 bigram 索引里不存在）。
   召回漏检，且语义默认关时无处补救。修法：按 CJK run 分段各自 bigram + ASCII 部分 `"word"*` 后 AND。
2. **provider 超时只约束单批**：`ensureEmbeddings` 循环无总预算，最坏 7×timeoutMs（冷启动 2.78s/次）
   → 违背 §14.4 "Never block the step"；且中途某批失败 → 前面已付费的批全部丢弃。
3. **向量维度只写不读** + cosine 取 min 长度：同名 model 换维度时静默算出垃圾相似度且不重建索引。
4. **子代理写权限只在 2 处生效**（`save`、`distill`）：`memory_forget` / `memory_consolidate` /
   `memory_sync` / `memory_reindex` 都不查 `mayWrite`，与 §9.3.5 不符。
5. **评估门禁在四项指标全为 null 时仍返回 `verdict: 'pass'`**，与"缺失即 unknown，不是静默通过"的注释相悖。

**中**
6. `slugify` 与遗留 `memory-lesson.sh` 规则不一致（BSD sed 不折叠连字符）：真实语料 21 条里 11 条不同名
   （`-fetch--origin` vs `fetch-origin`），同一教训可能出现两个 id、两条记录。
7. `maxAdditions` 按库生效（见 17）；`rank` 用 `times_seen` 而 DESIGN §6 写的是 `times_recalled`
   （"历史命中"反馈未落地）；`QueryVectorCache` 键只取前 24 个 term 且无 in-flight 去重。
8. 审计行不是"任何尝试都写"（skip/抛错路径不写），`pending.ts` 的幂等承诺不成立 → 同组信号可能反复重蒸。
9. 恢复仍有并发窗口：与仍在飞的 job 可能蒸同一组（已加 5s 新鲜度 + 轮次门槛，但非强保证）。
10. 脱敏规则漏常见密钥形态（AWS AKIA / x-api-key / Authorization Basic / glpat- / npm_ / AIza / DB URL / cookie）。
11. schema v1→v2 迁移顺序会抛 `SQLITE_CORRUPT` 并锁死该库（需 v1 库，当前潜伏）。
12. submodule 内项目根解析错（落到 `<super>/.git/modules`，多个 submodule 共用一个库）。
13. `setBaseline` 可由模型调用 → 可自行重冻门禁基准"洗掉"回归判定。

**低 / 文档漂移**
14. `inject` 列表与 DESIGN §9.2 不一致（实测无功能损坏）；`CAPABILITIES` 硬编码而非按注册结果。
15. 死代码：`LAYER_ORDER`、`HYPOTHESIS_THRESHOLD`、`scopeRootOf`、`openRootCounts`、`lessonPath`、
    `archivePath`、`recordsOf`、`turnVerdict`、`distillDigest`、`getLogFile`、`exportMetrics`。
16. 测试盲区：迁移无覆盖；CJK 混合词无覆盖；`test/recall.test.ts` 的预算断言恒真；
    `test/learn.test.ts` 曾手工 `observeTurn` 满足前置条件（掩盖 bug 10）；无任何"真实 rebase 冲突喂给
    `memory_sync`"的端到端用例（bug 7 就是这样逃逸的）。
